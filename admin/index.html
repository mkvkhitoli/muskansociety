How do I get a token?
  1. github.com → your photo → Settings → Developer settings
  2. Personal access tokens → Fine-grained tokens → Generate new token
  3. Name: Muskan CMS, Expiration: 1 year
  4. Repository access: Only select repositories → muskansociety
  5. Permissions → Repository → Contents: Read and write
  6. Generate, copy the token and paste it here

Every save updates the live website in about 1–2 minutes.
